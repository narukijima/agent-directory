# RESEARCH — 調査の入口

このProjectで進行中・完了した調査の入口である。研究の詳細は`docs/research/`が持ち、
確定して再利用できる結論だけをRoot Knowledgeへ昇格させる。

## 進行中

- `docs/research/color-contrast-study.md` — コントラスト基準を層ごとに変えるべきかの検証

## 昇格の扱い

- 昇格条件は`projects/DOCS.md#研究文書とKnowledge昇格`が所有する。
- 昇格した結論のactive正本はKnowledge側だけとし、ここには昇格先へのリンクだけを残す。
- 条件を満たさない結論はこのProject内に留め、Root Knowledgeとして扱わない。
