# 2.0.0 — Agent Skills標準pathへの移行

1.xの`skills/<name>/`をWorkspace正本にする独自二段構造を廃止し、Agent Skills標準の
`.agents/skills/<name>/`を正本にする。

## 一度だけ行う移行

1. `.agents/skills/<name>`が旧`../../skills/<name>`へのsymlinkなら、そのsymlinkだけを外す。
2. `skills/<name>/`の実体を`.agents/skills/<name>/`へ移す。
3. `.claude/skills/<name>`を`../../.agents/skills/<name>`へのsymlinkに張り直す。
4. 外部から取得したSkillは標準`skills` CLIでproject scopeへ再導入し、生成されたroot
   `skills-lock.json`をcommitする。Workspace自身が作るfirst-party Skillはlock不要である。
5. 旧`skills/SKILLS.md`、`skills/_template/`、空になったroot `skills/`を削除する。

ホームの`~/.agents/.skill-lock.json`はglobal install用であり、Workspaceへ移動・複製しない。
project scopeのlock名はroot `skills-lock.json`である。
